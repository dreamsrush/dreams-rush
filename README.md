# DREAMS RUSH — Loja virtual (atualizada)

Atualização visual e estrutural da loja.

## Alterações desta versão
- Nova paleta baseada no banner enviado: preto profundo, roxo/violeta, lilás e cinza.
- Banner Dreams RUSH incluído no site (`dreams-rush-banner.jpg`).
- Banner responsivo para celular e desktop.
- Modal de produto reorganizado com layout em duas colunas no desktop.
- Correção para manter nome, preço, tamanhos e botão de compra dentro da caixa do produto.
- Carrinho e checkout demonstrativo continuam funcionando.

## Publicação
Envie todos os arquivos desta pasta para o repositório do GitHub Pages.

## Importante
O checkout desta versão ainda é demonstrativo e não processa pagamentos reais. Para vender de verdade, é necessário backend, banco de dados, provedor de pagamentos, webhooks, estoque e frete.

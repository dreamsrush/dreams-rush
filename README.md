# Dreams RUSH

Projeto front-end responsivo de uma loja streetwear.

## Já funciona
- Página inicial
- Catálogo e filtros
- Página/modal de produto
- Seleção de tamanho
- Carrinho persistente no navegador
- Total automático
- Checkout demonstrativo
- Newsletter
- Visual roxo/preto inspirado em streetwear

## Para produção
O checkout é propositalmente demonstrativo. Para vender de verdade, conecte:
- backend + banco de dados
- provedor de pagamento (Pix/cartão)
- webhooks de pagamento
- estoque
- cálculo de frete
- painel administrativo
- domínio e HTTPS
- páginas de políticas, trocas e privacidade

Nunca coloque chaves secretas de pagamento no JavaScript do navegador.

## Publicação
Os arquivos `index.html`, `style.css` e `app.js` podem ser hospedados em um serviço de hospedagem estática. Depois, o domínio personalizado pode ser apontado para a hospedagem.
